Event Security

Ensure the safety and security of your event attendees

Why Event Security Matters

Proper security planning is essential for creating a safe environment for all attendees. UCF Police Department works with event organizers to provide appropriate security measures based on event size, type, and potential risks.

UCF Police Department Special Event Requests

🛡️

Request Security for Your Event

Submit a special event request to UCF Police Department to arrange security personnel for your event. This is required for certain event types and highly recommended for large gatherings.

Submit Security Request

When to Request Security

Contact UCF Police Department if your event includes:

  • Expected attendance of 100 or more people
  • Alcohol service
  • High-profile speakers or VIP guests
  • Outdoor events in public areas
  • Events with potential for controversy or protests
  • Events requiring traffic control or road closures
  • Late night or early morning events

Event Security Best Practices

Plan Early

Contact UCF Police Department at least 3-4 weeks before your event. Security arrangements take time to coordinate and may affect your budget.

Conduct Risk Assessment

Evaluate potential security risks based on event type, location, attendee demographics, and external factors. Document your assessment.

Communicate Security Plans

Brief all event staff and volunteers on security procedures, emergency exits, and who to contact in case of incidents.

Establish Check-In Procedures

For controlled-access events, establish clear check-in procedures. Consider guest lists, ID verification, or ticket scanning as appropriate.

Plan Emergency Exits

Know all emergency exits at your venue. Ensure exits are clearly marked, accessible, and never blocked by equipment or decorations.

Prepare Emergency Plan

Develop an emergency action plan covering medical emergencies, fire, severe weather, and other potential incidents. Share this plan with all staff.

Security Staffing Guidelines

Small Events (Under 100 attendees)

  • May not require dedicated security
  • Ensure event staff know emergency procedures
  • Have UCF Police phone number readily available
  • Consider security for evening events or those serving alcohol

Medium Events (100-500 attendees)

  • Recommended: 1-2 UCF Police officers
  • Additional event staff to monitor entrances/exits
  • Designated event security coordinator
  • Clear communication system for staff

Large Events (500+ attendees)

  • Required: Multiple UCF Police officers (determine number with UCFPD)
  • Security staff at all entrances and exits
  • Roving security personnel
  • Command center for security coordination
  • Medical personnel on standby

Special Security Considerations

Events Serving Alcohol

Events serving alcohol require additional security measures:

  • UCF Police presence is typically required
  • Check IDs at all entry points
  • Trained staff to monitor for intoxication
  • Plan for safe transportation options for attendees
  • Follow all UCF alcohol policies and state laws

Outdoor Events

Outdoor events present unique security challenges:

  • Define clear event perimeter and access points
  • Plan for weather emergencies and severe weather shelter
  • Consider lighting for evening portions
  • Secure equipment and displays from theft
  • Have contingency plans for weather-related changes

High-Profile Events

Events with VIPs, politicians, or controversial topics need enhanced security:

  • Early coordination with UCF Police (6-8 weeks in advance)
  • Possible background checks for close-proximity attendees
  • Screening procedures at entrances
  • Designated secure areas for VIP guests
  • Media management plan

Event Security Checklist

Before the Event

  • ☐ Contact UCF Police 3-4 weeks in advance
  • ☐ Complete risk assessment for event
  • ☐ Submit special event security request if needed
  • ☐ Confirm number of security personnel required
  • ☐ Include security costs in event budget
  • ☐ Develop emergency action plan
  • ☐ Identify all emergency exits and assembly points
  • ☐ Brief all staff on security procedures
  • ☐ Prepare emergency contact list
  • ☐ Arrange first aid supplies or medical personnel

During the Event

  • ☐ Security personnel at designated posts
  • ☐ Monitor all entrances and exits
  • ☐ Keep emergency exits clear and accessible
  • ☐ Maintain communication with security team
  • ☐ Monitor for safety hazards
  • ☐ Document any incidents or concerns

After the Event

  • ☐ Ensure all attendees have safely departed
  • ☐ Secure venue and equipment
  • ☐ Complete incident reports if necessary
  • ☐ Debrief with security personnel
  • ☐ Document lessons learned for future events
